# application_documenter

A collection of Python scripts for image and PDF processing:

## Scripts

### `img_compressor.py`
Compress JPEG images with adjustable quality. Supports RGBA/Palette to RGB conversion for JPEG compatibility.

### `imgtopdf.py`
Convert JPEG/PNG images to PDF with compression. Includes optional resizing and in-memory JPEG compression.

### `pdf_compressor.py`
Compress PDF files by re-compressing images and compressing content streams. Supports quality settings and page optimization.
